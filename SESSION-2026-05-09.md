### 1. Gemini AI Parser API Route
**File:** `src/app/api/lead-capture/route.ts`

A Next.js API route that receives lead data, calls Google Gemini 1.5 Flash to parse it, stores it in Supabase, and sends emails.

**What it does:**
- Receives POST with `token` and `body` (raw lead text)
- Looks up client in Supabase by token
- Calls Gemini API with structured JSON schema response
- Validates phone/email with regex
- Inserts lead into Supabase `leads` table
- Sends owner alert via Resend
- Sends customer auto-reply if email exists

### 2. Updated n8n Master Workflow
**File:** `workflows/master-workflow.json`

**Problem fixed:** The original workflow had a "Gemini AI Parser" node configured as a generic `httpRequest` node but with AI-specific parameters (`model`, `messages`) that don't exist on that node type. This caused n8n to silently fail on execution.

**Solution:** Rebuilt the workflow using only built-in n8n nodes:
- `Build Gemini Prompt` (Code node) — constructs the extraction prompt
- `Gemini AI Parser` (HTTP Request node) — POSTs to Google's API
- `Validate Lead` (Code node) — parses Gemini JSON response and validates fields
- `Fetch Client by Token` (HTTP Request) — GET to Supabase REST API
- `Insert Lead to Supabase` (HTTP Request) — POST to Supabase REST API

**Required n8n env vars:**
```bash
SUPABASE_URL=https://qzkpdwvrrnychbmmwazf.supabase.co
SUPABASE_SERVICE_ROLE_KEY=...same as above...
GOOGLE_AI_API_KEY=AIzaSy...
```

## Node Wiring (n8n)

Connect these in order:
1. `Webhook Trigger` → `Extract Token + Text`
2. `Extract Token + Text` → `Fetch Client by Token`
3. `Fetch Client by Token` → `Enrich with Client Data`
4. `Enrich with Client Data` → `Build Gemini Prompt`
5. `Build Gemini Prompt` → `Gemini AI Parser`
6. `Gemini AI Parser` → `Validate Lead`
7. `Validate Lead` → `Insert Lead to Supabase`
8. `Insert Lead to Supabase` (top output) → `Owner Alert Email` → `Respond to Webhook`
9. `Insert Lead to Supabase` (bottom output) → `Has Customer Email?`
10. `Has Customer Email?` (true/top) → `Customer Auto-Reply` → `Respond to Webhook`
11. `Has Customer Email?` (false/bottom) → `Respond to Webhook`
